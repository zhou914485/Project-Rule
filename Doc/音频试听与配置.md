# 音频试听与配置

基础音效选材为31个事件、33份素材、41个变体引用，另有3项主界面按钮事件和19项独立 Boss 事件，目前共53项可配置事件。分类试听、逐项试听、新旧等响度对照与选材理由见 [选材试听](AudioPreviews/SourceSelection/README.md)。素材准备没有使用EQ；音乐仍为0.25。历史迭代记录见下方，旧试听不代表当前选材。

入口：**Tools → 音频工作台**。也可以选中 `PlayerWheel_SfxBank.asset`，在 Inspector 点击“打开音频工作台”。无需进入 Play Mode，窗口只负责编辑音频资产和播放临时试听，不会创建场景物体。

主界面按钮新增“主界面 · 按钮点击 / 关闭返回 / 确认退出”三项音效，在工作台 **主界面** 分类下调整。沿用固定音效池和界面通道，菜单暂停世界时仍可播放；鼠标实际点击及键盘/手柄确认均经 Button.clicked 触发，开始按钮隐藏菜单前先发声。界面重新启用会清理旧订阅，不重复叠音。

已撤销上一轮将轮盘六项 UI 音效恢复旧版的操作，轮盘回到该操作前的素材与参数。

主界面音效在原工程 Unity 6000.6.4f1 中编译并通过35项定向 PlayMode 检查，使用真实 Boot 按钮的 NavigationSubmitEvent，覆盖暂停时的实际声源、非零PCM、关闭返回、退出确认、开始隐藏菜单、禁用按钮和重复启用后的单次播放。结果位于 `Logs/MainMenuSfx/Validation.txt`；未做人工设备听感验收或 Player 构建。

## 换音效、调参数

1. 左侧用“Src 源素材”或“选目录…”浏览任意音效文件夹，点击文件立即试听，搜索会包含子目录；无需先导入。右侧按玩家、轮盘、敌人、Boss、机关、主界面分类，或输入中文名称 / 英文 Cue 搜索。
2. 点击事件（例如“挥剑 · 轻击”）即按配置随机试听，也可点击下方变体名称逐个试听。参数试听包含事件音量、随机音高和试听主音量；“原声试听”不应用这些参数。
3. 从左侧拖到右侧事件可添加变体（可多选），拖到某个变体槽会只替换该槽，也支持项目 AudioClip 和资源管理器文件。外部素材只在拖入时复制至 Imported，并记录来源与哈希；重复拖入复用资产。撤销恢复配置引用，已导入文件会保留。所有引用这份配置的对象会使用新素材。
4. 调整事件音量、音高范围，边改边听。高级选项一般保持原值。
5. Ctrl/Cmd+Z 可撤销，点击顶部“保存配置”写入资产，再把资产与新音频、对应 `.meta` 一起提交到 Git。建议退出 Play Mode 后调音，避免混淆试听与实际游戏声音。

| 配置项 | 用途 |
| --- | --- |
| 事件音量 | 当前事件本身的音量，0–1 |
| 随机音高范围 | 1 为原速；小于 1 更低更慢，大于 1 更高更快；上下限相同即固定 |
| 素材变体 | 同一事件的不同音频，游戏中随机选择并尽量不连续重复 |
| 最短间隔 | 同一发声物体的重复限频；玩家与轮盘沿用各 Cue 的限频 |
| 同类最多并发 | 固定池内同一 Cue 最多同时播放几份 |
| 优先级 | 数值越小越优先，决定池满时谁能替换旧声音 |
| 试听主音量 | 仅影响本窗口，默认 0.85；不会修改游戏的总音量 |

实际游戏音效总音量在 `LevelRuntime.prefab` 的 `SfxPlayer.Volume`，听距在 `Hearing Distance`。本窗口参数试听忽略距离、声像、并发、暂停和冷却，便于反复比较；完整混音仍应在游戏中确认。短音效参数试听支持 15 秒内、Decompress On Load 的素材（处理后的样本数设有内存上限），项目现有音效均满足；不兼容的素材会在状态栏提示，可先用原声试听，不会擅自修改导入设置。

## 调区域音乐

“区域音乐”页集中列出积木、时钟、毛绒三份 MusicProfile。可更换前奏和循环段、调整游戏内音量及跨区淡化时长。

- “前奏原声”：单独听前奏；没有前奏的区域会提示未指定素材。
- “循环原声”：循环播放整段，点顶部“停止试听”结束。
- “循环接点原声”：从末尾 3 秒开始循环，方便检查尾→头接点。
- “打开音乐试听场景”：打开既有 `Test_AreaMusic`，进入 Play Mode 后在三个区域间移动，验证前奏接循环、跨区淡化和暂停压低。打开其它场景前，编辑器会提示处理未保存的场景。

音乐原声预览不应用 MusicProfile 音量、淡化或前奏调度。试听停止、关闭窗口、重载脚本和进入/退出 Play 时都会清理本工具的临时声音。

## 哪些需要改代码

替换现有事件的素材、调整音量/音高/限频/并发、替换地区音乐，都可以直接改配置。普通敌人与 Boss 的受击、死亡沿用木质、金属、毛绒组；修改一组会影响这一组的全部敌人。Boss 新增动作与能力在独立 Boss 分类里调整。新增玩法事件，或让某个敌人改用独立音效组，仍需增加 Cue / 表现事件映射，然后在配置中放素材。

菜单①、④、⑥用于补接线，不是日常调音入口。现在重跑会保留已有音效条目，以及已有音乐配置的素材、音量和淡化；⑥仅补缺失项，不再重置挥剑调音。资产路径和 Cue 序号保持不变。
