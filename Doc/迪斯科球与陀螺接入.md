按 2026-10-20 晚间策划说明实现。蜘蛛暂不制作。交付分支 `feat/enemy`。

## 放进地图

从 `Assets/_Project/Prefabs/Enemies/FieldMinions/` 拖入：

- `DiscoBall.prefab`：放在希望悬挂的位置，始终固定，不追人，不受击退或重力拖动。预警 → 360° 连续辐射 → 停火 → 再次预警。墙和平台实时遮挡，移动平台经过时形成随之移动的安全阴影。低亮预警和停火都不造成伤害。
- `SpinningTop.prefab`：脚部放到地面上方，旋转并沿水平方向平移；碰到玩家、小怪、另一只陀螺或动态刚体时，按双方质量交换等大反向冲量。静态墙只能让陀螺反弹；按固定路径移动的平台继续沿原路径运动。到活动边界折返。

在已有可玩地图中自动绑定玩家、战斗服务和规则，不需要额外拖线。地形继续使用工程既有 Ground 层；角色身体与受击箱分开，辐射只检查正规 Hurtbox。空白场景仍需地图自己的玩家、地形和规则启动器。

## 参数

点击预制体的「敌人配置」，中文面板可调整：

| 参数 | 当前默认值 |
| --- | --- |
| 辐射半径 | 8 |

| 辐射伤害间隔 | 0.5 秒 |

| 陀螺生命 / 接触伤害 / 移速 | 25 / 8 / 3.5 |

两者复用既有 HFSM、伤害/因果结算、暂停、规则实体登记和世界快照。时间失效冻结辐射周期与持续伤害间隔，动作继续；陀螺的实际质量参与碰撞反作用。摩擦反转时边界和反弹使用实际世界运动方向。回溯恢复周期、朝向、冲量和接触保护，视觉也跟随恢复。辐射不是投射物，既有投掷物脚本与资源均未改。

## 彩色辐射表现

按用户要求将单色绿光升级为流动彩虹底色、两组反向旋转光束、外扩环纹、镜面亮片和柔和节拍脉冲。辐射底色始终连续，不能将光束之间较暗的彩色带误认成安全区；掩体阴影仍完全不透光。预警使用低亮暖色，停火直接隐藏光区。颜色与图案由实体机制时钟驱动，暂停和回溯跟随原有状态，不使用 Shader 自行累计的墙钟时间。

这次只调整辐射 Shader，伤害、遮挡、半径与周期没有改。Unity 实际渲染验证了红/绿/蓝三类色区、阴影像素、暂停冻结和恢复流动；重复 GPU 渲染允许一个 8-bit 色阶的量化误差。新功能 102 组及集中场景 11 项均通过，无 Shader 编译错误；日志 `/tmp/rule-disco-top-effects-final.log`、`/tmp/rule-disco-top-effects-scene2.log`。实际渲染动图 `Doc/特效预览/DemonMinions/DiscoRainbow.gif`，未做完整打包或 GPU 性能测量。
