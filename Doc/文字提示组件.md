# 文字提示（WorldHintText）

> 世界空间的文字提示：按键教程、机关说明、路牌。默认排在**背景层**，不挡玩法、不抢输入。

## 1. 现状

| 项 | 值 |
|---|---|
| 组件 | `Assets/_Project/Scripts/Presentation/Scene/WorldHintText.cs` |
| 生成菜单 | `Tools/规则游戏/提示/① 文字提示（背景层）` |
| 生成结果 | Scene 视图中心出现 `HintText`，自带一个同步的 `Shadow` 子物体 |
| 渲染 | 旧版 `TextMesh` + 工程里的 Noto Sans CJK |
| 自检 | `规则游戏/验证/文字提示（组件 + 隔离场景）`（21 项，编辑模式，不进 Play） |

它不是 UI：没有 Canvas、没有碰撞体、没有刚体、不读任何按键。
屏幕上的 HUD / 对话框仍然走 `RuleGame.UI`（UI Toolkit）。

## 2. 放在背景层

工程只有 `Default` 一个排序层，一切靠 **Order in Layer** 数值：

| 对象 | Order | 说明 |
|---|---:|---|
| `Bg_Far` 远景背景 | −30 | 天空 / 远山 / 视差 |
| `Bg_Near` 近景背景 | −20 | 墙后装饰、管线 |
| **`WorldHintText`** | **−10** | 默认值：压在背景装饰前、逻辑与角色后 |
| `Logic` 白盒 | −2 | 逻辑层 |
| 玩家 | 0 | |
| 敌人 | 5 | |
| `Fg_Decor` 前景装饰 | 20 | 挡在玩家前面 |
| 屏幕效果 | 100 | 淡入淡出 |

- 想让提示压在角色前面：把 **Sorting Order** 改成 `10`。
- 想更靠后（贴在最远的背景上）：改成 `-25` 之类，但别低于 `-30`，否则会被远景盖掉。
- 组件不要求特定 Layer；它没有碰撞体，放哪个 Layer 都不影响物理。

## 3. 常见配法

| 用法 | 触发半径 | 停留 | 只显示一次 | 说明 |
|---|---:|---:|---|---|
| 墙上的常驻教程 | `0` | `0` | 关 | 文字像画在墙上，一直在；适合「A / D 移动」这类第一眼教程 |
| 走近才出现的按键提示 | `4` ~ `6` | `3` ~ `4` | 开 | 第一次没看清，离开再回来不会重弹；需要时脚本调 `ResetHint()` |
| 给机关 / NPC 的说明 | `2` ~ `3` | `0` | 关 | 把提示挂成机关的子物体，跟着机关走；排序可改 `10` |
| 剧情 / 教学序列 | 任意 | 用 `ShowFor(3f)` | — | 由脚本触发，不依赖玩家距离 |

## 4. 字段

### 文字

| 字段 | 默认 | 说明 |
|---|---|---|
| **Text** | `按 A / D 移动　空格 跳跃` | 多行文本；回车就是换行。支持富文本 |
| Font Size | `64` | 字号；配合 Character Size 决定最终大小 |
| Character Size | `0.07` | 世界尺寸。实测 `0.07` ≈ 一行字高 **0.65 m**（镜头正交 4 时约占屏幕 1/12） |
| Color | 暖白 | 背景很亮时改深色，或用富文本单独给几个字改色 |
| Anchor | `MiddleCenter` | 整块文字以哪个点对齐；路牌可用 `MiddleLeft` |
| Alignment | `Center` | 行内水平对齐 |
| Line Spacing | `1.15` | 行距倍率 |
| Rich Text | 开 | 关掉后 `<b>` 等标签按原样显示 |

### 层级 / 阴影

| 字段 | 默认 | 说明 |
|---|---|---|
| Sorting Order | `−10` | 背景层；见 §2 |
| Shadow | 开 | 在文字后面垫一层深色字，浅色背景也读得清 |
| Shadow Color | 黑 60% | 浓度会再乘当前淡入透明度 |
| Shadow Offset | `(0.035, −0.035)` | 阴影相对文字的偏移（世界单位） |

### 出现条件

| 字段 | 默认 | 说明 |
|---|---|---|
| Trigger Radius | `6` | 玩家进入这个半径才淡入；**0 = 一直显示**。距离按提示自身位置算 |
| Show Delay | `0` | 进入半径后等几秒再淡入，防止跑过时一闪而过 |
| Hold Duration | `0` | 完整显示后停留几秒自动收起；0 = 待在里面就一直显示 |
| Show Once | 关 | 第一次完整显示后，离开再回来不再出现；`ResetHint()` 可解锁 |

### 表现

| 字段 | 默认 | 说明 |
|---|---|---|
| Fade Duration | `0.25` | 淡入 / 淡出秒数，非缩放时间；0 = 瞬间 |
| Bob Amplitude | `0` | 上下浮动幅度（米）；悬浮提示可给 `0.03`，墙上的字保持 0 |
| Bob Speed | `1.2` | 浮动速度（每秒来回次数） |

## 5. 文字写法

- Inspector 的 **Text** 是多行框，**回车就是换行**；TextMesh **不会自动折行**，每行长度自己控制。
- 富文本示例：

  ```text
  <color=#FFD166>A / D</color> 移动　<color=#FFD166>空格</color> 跳跃
  <b>按 E</b> 扳动拉杆
  ```

  支持 `<b>`、`<i>`、`<color=#RRGGBB>`、`<size=90>`；关闭 Rich Text 后按原样显示。
- **字体**：生成器已经挂好 `NotoSansCJKsc-Regular.otf`。手动给物体加组件时要自己把字体拖到 `TextMesh` 上，否则中文显示成方块。
- `Shadow` 子物体由组件自动创建和同步，不要手改它的文字 / 颜色 / 尺寸。

## 6. 代码接口

```csharp
using RuleGame.Presentation.SceneComponents;

var hint = GetComponent<WorldHintText>();

hint.Text = "摩擦失效后，箱子一推就滑。";
hint.Show();          // 无视半径，一直显示到 Hide / ResetHint
hint.ShowFor(3f);     // 显示 3 秒（剧情 / 教学序列常用）
hint.Hide();          // 收起，离开半径前不再自动弹出
hint.ResetHint();     // 清掉「只显示一次 / 手动收起」，重新按半径出现

hint.OnShown += () => PlayHintSound();
hint.OnHidden += () => { };
```

- `Tick(float dt)` 是给验证 / 测试用的**确定性推进**；正常运行时由 `Update` 用 `unscaledDeltaTime` 调。
- `RefreshVisual()`：运行时换了 TextMesh 字体后调一次；改 Inspector 字段会自动调。
- `HasShown` / `IsVisible` 只读，适合条件分支。

## 7. 注意 / 已知边界

- **距离按提示自身位置算**，不是按相机或屏幕。挂在墙高处时，半径要覆盖玩家站立的位置，
  或者干脆把提示放到齐眼高度。
- 淡入淡出用**非缩放时间**：规则轮盘暂停、慢时间规则不会把它拖慢；暂停时提示仍然可见。
  如果暂停时想隐藏，在暂停流程里 `Hide()`。
- `ShowOnce` 只在**重新进入半径**时拦截；正在显示时不会被自己关掉。
- `ShowFor` 到点后会挡住半径逻辑，防止下一帧又弹出来；想再显示用 `ResetHint()`，或离开再进。
- 没有碰撞体，不会被纸飞机 / 攻击打到，也不参与 `IContactSwitch`。
- `Bob` 改的是 `localPosition`，基线在 `Awake` 记录；运行时请移动父物体，不要直接改这个物体的位置。
- 不参与存档 / 世界快照（约束 C5）：`ShowOnce` 是本次运行的状态，重开关卡会重新算。
  跨关卡的「已看过教程」需要的话，应由关卡流程显式调用 `Hide()` / `ResetHint()`。
- 阴影是第二个 TextMesh；不需要就在 Inspector 关掉 Shadow，子物体会一起停用。

## 8. 自检

菜单 `规则游戏/验证/文字提示（组件 + 隔离场景）` 会新建一个**附加空场景**，
造一个提示 + 假玩家，用 `Tick()` 逐帧推进，覆盖 21 项：

默认排序 −10、阴影子物体同步 / 排序 / 偏移、半径淡入淡出、`OnShown` / `OnHidden`、
`ShowOnce` 再进入拦截、`ResetHint`、`Hide`、`ShowFor`、`Text` 同步、阴影开闭、
半径 0 常显、`Hold` 自动收起、`ShowDelay`。

跑完自动关闭空场景，**不进 Play**，不碰当前正在编辑的关卡。
