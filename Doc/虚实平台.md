# 虚实平台（按钮切换实化 / 虚化）

> 组件：`Gameplay/Scene/PhasePlatform.cs` + `PhasePlatformGroup.cs` + `PhaseButtonRelease.cs`
> 菜单：`Tools/规则游戏/地图组件/⑯ 虚实平台（按钮切换）`

---

## 1. 一句话

一块**能按按钮翻面**的平台：**实化**时是一块能站、能挡路的地面，**虚化**时只剩半透明轮廓，
玩家 / 敌人 / 纸飞机 / 石头全都穿得过去。初始是实是虚可以在 Inspector 里选。

**每块平台顶面上站着一个按钮。按钮是点按式的** —— 按一下翻一次，按完立刻回到「未按下」，
所以**任何一块平台上的按钮、在任何时候都能再按**；按任意一个 → 整组平台一起翻。
**按下后隔 0.5 秒**才真正切换（碰撞体与外观一起变），给玩家留出从平台上跳走的时间。

## 2. 怎么摆

### 一键（推荐）

菜单 **⑯ 虚实平台（按钮切换）** 生成：

```
PhasePlatforms              ← 根：PhasePlatformGroup，所有按钮都指向它
└─ PhasePlatform            ← Ground 层，BoxCollider2D + PhasePlatform
    ├─ Art                  ← 白盒方块（P4WhiteboxSquare）
    ├─ Label                ← 「实化 / 虚化」
    └─ PhaseButton          ← CityButton 实例，站在平台顶面上（点按式）
```

生成时按钮已经配好三样：

- `Toggle = false` —— **点按式**：按一次由平台翻转一次，按完平台把按钮复位
  （勾上 `Toggle` 反而会变成拉杆：按钮自己记着开 / 关，会吃掉别的按钮的按下）；
- `FollowMotor = PhasePlatformGroup` —— 按**任意一个**按钮都翻**整组**平台；
- 交互键 E / 手柄 Y（`CityInteractor` 自己读），也吃玩家攻击盒与纸飞机（`ImpactByContact`）。

按钮是平台的**子物体**：复制 `PhasePlatform` 时按钮会一起复制，而且 `FollowMotor`
仍然指向同一个组。复制完点一下组 Inspector 的「从子物体收集平台」，新平台就接上了。

### 之前摆好的平台 / 按钮还是拉杆式

菜单 **⑯a 虚实平台：补按钮 + 统一切换时间（当前场景）**：

- 给还没有按钮的平台补一个（顶面正中）；
- 把接在本组上的**所有**按钮改回点按式（`Toggle = false`、`IsOn = false`）；
- 把场景里所有平台的 `_switchDelay` 统一成 **0.5 秒**；
- 把所有平台收进同一个组（有组就复用，优先平台父链上的；没有就新建 `PhasePlatforms` 根）；
- 幂等：重复点不会重复加按钮 / 平台。

全部走 Undo，**改完记得保存场景**。

### 手工

1. 平台上挂 `BoxCollider2D`（实心）+ `PhasePlatform`，**物体必须在 `Ground` 层**；
2. 把 `CityButton` 拖成平台的子物体，摆在平台顶面（碰撞体高 0.35 → 中心抬到顶面 + 0.175）；
3. 按钮 **`Toggle` 不勾**（点按式），`PressByPlayerProximity` 不勾，`FollowMotor` 拖 `PhasePlatformGroup`；
4. 多块平台都放进同一个组（组 Inspector 可一键收集）。

单块平台也可以不用组：直接把 `PhasePlatform` 拖到按钮的 `FollowMotor`（它自己实现了 `ISwitchTarget`）。

## 3. 参数（`PhasePlatform`）

| 字段 | 含义 |
| --- | --- |
| `_startsSolid` | **初始状态**：实化（能站、挡路）/ 虚化（半透明、穿得过去） |
| `_art` | 外观用的 `SpriteRenderer`。留空自动取名为 `Art` 的子物体；玩法判定不读它 |
| `_solidTint` / `_etherealTint` | 实化 / 虚化时的颜色（后者 alpha 就是可见强度，默认 0.28） |
| `_fadeSeconds` | 切换后外观淡入淡出耗时（0 = 瞬间） |
| `_switchDelay` | **按下后隔多久真正切换（默认 0.5 秒）**。0 = 按下立刻切 |
| `_label` | 白盒标签，自动写「实化 / 虚化」。接正式美术时清空 |
| `_waitForPlayerToClear` | 实化时玩家正占着平台空间 → 等他自己走出来再实化（默认开） |

## 4. 为什么这么实现

### 虚化 = 摘掉碰撞体

玩家的位移走 `Rigidbody2D.Slide`、纸飞机走自己的 `CircleCast` —— 两边都只认
「世界里有没有这块碰撞体」。所以虚化就是把 `BoxCollider2D.enabled = false`，
**不换层、不用 `PlatformEffector2D`**（它管不到 Kinematic 的 `Slide`），
玩家 / 敌人 / 投射物都不需要认识这个组件。与 `OneWayGate` 同一条路子。

### 点按式按钮：每次按下翻一次，不看按钮自己的状态

`CitySwitch` 有两种模式：

- `Toggle = true`（拉杆）：按钮自己记着开 / 关。**多块平台各有一个按钮时，其它按钮的状态
  和平台不同步** —— 按下一个「自己记着开」的按钮，送出去的请求可能和当前状态一样，
  看起来就是「按了没反应」。
- `Toggle = false`（按钮）：按一次就把 `IsOn` 置真并锁住，自己不会弹回来。

虚实平台要的是「点按」：**平台把每一次 `SetSwitchState` 调用当成一次按下，自己翻转，不看传进来的值**。
然后由平台 / 组把接在自己身上的按钮 **复位成 `IsOn = false`**（`PhaseButtonRelease`），
下一次按就是完整的一次按下。于是：

- 按钮不保持开 / 关状态 —— 不是拉杆；
- 任何一块平台上的按钮、任何时候都能按；
- 按钮被石头 / 敌人压到时，`ReleaseByContact` 在 `Toggle = false` 下被忽略 —— 一次接触只翻一次。

同一帧里多路来源（近战 + 纸飞机、多个按钮）只算一次按下（`Time.frameCount` 去重）。

### 延迟 0.5 秒：给玩家跳走的时间

按钮就在平台顶面上 —— 按下去之后平台马上消失的话，人还站在上面就掉下去了。
所以每次按下只**排一个倒计时**（`_switchDelay`），到点才一起改碰撞体和外观：

- 按下 → 0.5 秒内可以跳走 / 走到安全位置；
- 倒计时期间再按一次会**从队列里的目标态继续翻**（连按两下 = 取消，不会只翻一次）；
- 整组平台在同一帧收到转发，倒计时同时开始、同时到点，看起来就是整组一起翻；
- 暂停时倒计时也停住（读 `TimeManager.Instance.IsPaused`）。

### 初始状态

`PhasePlatform` 开局按 `_startsSolid` 摆好，之后每按一次翻一次。
同一组里初始状态不同的两块平台会**一直保持相反** —— 开局就一实一虚，按一下一起翻过去。

### 玩家占着空间时推迟实化

直接把碰撞体塞进 Kinematic 玩家身上，`Slide` 不会把人排出去，只会把人卡在墙里
（`SpringBackBody` 踩过同一个坑）。所以倒计时到点、要实化时先用 `OverlapBox` 查一次玩家
（`PlayerLookup`，身体或受击箱都算），有人就挂起，`FixedUpdate` 里等他离开再实化。
虚化随时立刻生效。

查询盒会先缩 `0.05` 单位：`OverlapBox` 把「刚好贴着」也算重叠，不缩会在平台挨着地面、
玩家站在边上时误判。

## 5. 注意

- ⚠️ **必须在 `Ground` 层**（层 8）。玩家的 `Slide` 与接地探测只认这个层，放错层就是一块穿得过去的空气。
  平台 Inspector 会直接报错。
- ⚠️ 碰撞体必须是**实心**（不勾 `Is Trigger`）；是 Trigger 就什么也挡不住。
- ⚠️ 按钮 **`Toggle` 不要勾**（勾了就变拉杆，会吃掉别的按钮的按下）；组 Inspector 会报警。
  也不要开 `PressByPlayerProximity` —— 踩上去就按的按钮不会被复位，会一直锁住。
- **平台虚化后按钮还留在原地**（按钮是平台的子物体、不参与碰撞开关），所以人掉下去之后
  还能再按一次把平台变回来 —— 这是有意的。
- 站在虚化平台上的东西会掉下去；平台在铁箱 / 石头底下虚化，它们也会掉 —— 都是物理自己算的，没有特判。
- 平台是**静态碰撞体、没有刚体**：不参与时间回溯（与多数地图组件一致）。
- 暂停时外观过渡、切换倒计时与「等玩家让开」都停住（读 `TimeManager.Instance.IsPaused`）。

## 6. 自检

- 平台 Inspector：层 / Trigger / 外观三项配置错误会直接显示成 Error / Warning；
  Play 模式还会显示「切换倒计时」还剩几秒。
- 组 Inspector：显示「N / M 块已接」「已接按钮：N」，并检查按钮是不是点按式
  （勾了 `Toggle` 或开了 `PressByPlayerProximity` 都会报警）。
- 场景视图 gizmo：**绿框 = 实化（挡路），青框 = 虚化（穿得过去）**。
