# 火车快速传送

> 状态：**代码已落地、编译通过；场景实例与运行时冒烟未做**（关卡里的车由关卡负责人摆）。

---

## 0. 一句话

**车是布景，人瞬移。** 砍一下车 → 弹出线路面板 → 选站 → 黑场 → 落人 → 该站成为复活点。

三条定调（2026-10-19）：
1. 车不带碰撞、不带刚体，纯视觉；
2. 跨场景传送走「站点目录 + 预加载」；
3. 每台车带一个复活点，传送到达即存档。

---

## 1. 为什么车不自己跑

原来的 CityTrain 是「两站往返平台」（CityPathMotor：14 m、3 m/s、到站停 2 s、带人）。
快速移动不需要过程，只需要结果 —— 留着路径运动会同时背上承载、挤压检测、到站事件三套逻辑，
而且跨场景传送根本没法用路径表达。所以车只保留视觉，逻辑搬到独立的服务上。

⚠️ 旧的 Prefabs/BrickCity/CityTrain.prefab **一行没动**：它还是白盒第 8 区那台会动的车，
两套并存，互不影响。

## 3. 一次传送的时序

1. **命中**：玩家挥砍（PlayerController.PressSwitches）或纸飞机撞上车站的 Trigger →
   TrainStation.ImpactByContact → TrainTravelService.RequestOpen。
2. **就近校验**：一次挥砍可能同时罩到两台车，服务按玩家位置取 3 m 内最近的那台。
3. **开门禁**：锁玩家输入（BlockGameplayInput）+ PushScale(TimeSource.UI, 0.001)
   （与规则轮盘同一套，不用 SetPaused）。
4. **面板**：列出目录 + 在场站点；当前位置那一行置灰；**未解锁的站也列出来，但压暗且选不了**。
5. **确认** → Travel(id)：黑场 FadeTo(1)。
6. **按需加载**：目标不在场时 WorldStreamer.EnsureLoaded(场景路径)，会先把分区**钉住**再加载
   （不钉住的话，下一个 0.2 s 的 Refresh 会因为它「不在玩家附近」立刻卸掉）。
7. **落人**：PlayerController.TeleportTo(RidePoint)（清速度 + 写刚体位姿 + SyncTransforms）。
8. **刷复活点**：station.NotifyArrived(player) → PlayerSpawnPoint.Activate。
9. **收尾**：恢复时间倍率（相机是阻尼跟随，倍率不恢复就永远追不上）→ 黑屏留 0.5 s →
   FadeTo(0) → 释放输入租约 → 解除钉住。

## 4. 解锁（2026-10-19 追加）

**记录在玩家身上，不在车站身上。** 车站是场景物件，会随分区卸载消失；进度属于玩家。
`TrainPass` 按需挂到玩家身上（`TrainPass.Ensure`），存的就是一串站点编号。

三条解锁途径，都汇到 `TrainStation.Unlock(player)`：

| 途径 | 字段 | 用途 |
|---|---|---|
| 开局开放 | `_unlockedAtStart` | 出生站 / 剧情已开放的站 |
| 走近即解锁 | `_unlockRadius`（默认 2.5 m，距离轮询） | 默认玩法：到过就能当目的地 |
| 外部调用 | `Unlock()` + `_onUnlocked` | 开关 / Boss 清场 / 剧情。想做成「按开关才开」就把半径设 0 |

- **到达即解锁**：`NotifyArrived` 先 `Unlock` 再刷复活点 —— 坐车到的站当然算到过。
- **面板**：未解锁的行显示「未解锁」并压暗；确认时提示「先到现场把它启动」。
- **完全不能用（2026-10-19 修）**：锁着的车站被打中时 `ImpactByContact` 直接返回 —— **连面板都不开**。
  之前只在目的地那一侧拦，于是「站在锁着的站上，打车就能去别处」，等于这座站还是能用的。
  `RequestOpen` 与 `Travel` 各再查一次车票，绕开 UI 直接调也传不过去。
- **关闭按钮**：面板右上角有「关闭」；Esc / 手柄东键同样有效。误触叫出来的面板不会把人困住。
- **外观**：未解锁时把美术**原色**乘上暗色系数（≈0.36、alpha 0.82），解锁后恢复原色
  （记原色再相乘，作者调过的颜色不会被洗掉）。⚠️ 这是**运行时状态**：编辑器的场景视图里看到的是源色。
- **存档**：将来只需要写 `TrainPass.UnlockedIds`（一串编号，约束 C5），位置与名字仍由场景提供。

⚠️ 目前是**运行时内存**：重开 Play 就清零。落盘等 `ISaveSystem`。

## 5. 预制体结构

```
TrainStation            (层 0，无刚体，无实心碰撞)
├─ BoxCollider2D        Trigger，4 × 1.2，攻击盒靠它命中
├─ TrainStation         编号 / 名字 / 落点引用
├─ Visual               CityTrain 的精灵（与原预制体完全一致）
└─ RidePoint            落点（局部 y = 0.55）
   └─ PlayerSpawnPoint  复活点（编号同站，落点即存档点）
```

**为什么 Trigger 放层 0**：层 8 会被玩家接地探测与 Slide 看见；层 10 会被 CombatSystem
当成受击箱。攻击盒查询（PressSwitches）不配 mask，放哪层都打得到。

## 7. 黑场

- 玩法层只依赖 Gameplay/Common/IScreenFade：

```csharp
bool IsCovered { get; }
IEnumerator FadeTo(float alpha);
```

- 现成实现是 SwingCheckpointFade（Alpha + OnGUI），适配器 SwingCheckpointFadeScreen
  按**非缩放时间**插值（面板把 timeScale 压到 0.001，用 deltaTime 的话一次淡入要 250 秒）。
- **黑屏期间的等待也一律非缩放**：落人之后的 `_settleSeconds` 原来是 `WaitForSeconds`（缩放时间），
  只要黑屏里有人把 `TimeSource.UI` 压到 0.001（例如规则轮盘），这 0.5 秒会变成几分钟的
  「只有淡入没有淡出」。现在用手动 `unscaledDeltaTime` 循环。
- **轮盘不能开在黑屏上**：`RuleWheelPresenter.TryOpen` 现在要求 `PlayerController.IsInputBlocked == false`。
  过场 / 传送 / 对话拿着输入门禁时，轮盘拒绝打开 —— 否则玩家可以在存档过场里放规则，
  而慢时间又会把过场卡在黑屏上（2026-10-19 用户实测）。`IsInputBlocked` 与
  `IsGameplayInputSuppressed` 只差「释放后的恢复帧」，所以轮盘自己关掉的那一帧仍能立即重开。
- 以后黑场换成 Canvas/UI 覆盖层：只改适配器，传送侧一行不动。
- **没接黑场也能跑**：_fadeBehaviour 留空就直接瞬移。

## 8. 已知限制

1. **运行时没跑过**：编译通过、静态检查可跑，但 Play 冒烟还没做。第一次进场景请先看控制台。
2. **攻击入口受「拔剑」影响**：策划定了「拔出断剑才有攻击能力」。那条接线一做，
   火车就会跟着被锁死 —— 到时要么允许无条件叫车，要么给车站补一个 E 入口
   （注意 CityInteractable 继承 CityMechanism，会把刚体 + 快照塞回布景，需要另抽接口）。
3. **纸飞机能远程叫车**：投射物撞 Trigger 也会调 ImpactByContact。如果不想让玩家隔着半张图叫车，
   在 TrainStation.ImpactByContact 里加距离判定即可。
4. **跨场景只认分区表里的场景**：目标场景必须在 PartitionCatalog 且进了 Build Settings，
   否则只报错不传送。
5. **传送不撤销**：玩家位置进世界快照（RuleAffectedBody 在玩家身上），按 Q 回溯会把人拉回传送前 ——
   与白盒 F1/F2 的表现一致，属于预期。
6. **复活点是「到站即存档」**：落人后由 `TrainStation.NotifyArrived` 显式调 `PlayerSpawnPoint.Activate`，
   不依赖玩家攻击。`PlayerSpawnPoint` 本身已改成攻击触发，走近不会再自动记录；
   如果给站台落点挂了 Trigger 碰撞体，攻击它也会触发（一般不需要）。
7. **未解锁的站仍会显示名字**：面板只做了置灰 + 「未解锁」，没有做「？？？」。
   要藏名字得给目录条目加一个开关，面板再按它改文案。
8. **解锁只在内存里**：重开 Play 清零。落盘时写 TrainPass.UnlockedIds 即可，不要在车站上再存一份。
