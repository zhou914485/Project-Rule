# 音效选材试听（当前接入版本）

按整个音效库重新选材，共31个事件、33份播放素材、41个变体引用。改变的是底材和搭配，没有使用EQ、低通、高架或烘焙升调。木/金属/柔软保留材质区别，清亮不等于全部改成铃声。播放文件仅裁切、短淡入淡出、增益平衡；少数事件使用清单注明的拟音叠层。

## 分类试听

合集按当前银行事件音量 × 主音量0.85、平均随机音高导出；无BGM、距离衰减或同时战斗的混音。每项间隔0.4秒，实际声音尾部不强行截断。游戏里的最终听感仍需人工判断。

- [Player.wav](Player.wav)：跳跃 → 多段跳 → 蹬墙跳 → 落地 → 冲刺 → 轻击 → 重击 → 玩家受击
- [Wheel.wav](Wheel.wav)：轮盘展开 → 轮盘预览 → 轮盘确认 → 轮盘取消 → 轮盘返回 → 轮盘拒绝
- [World.wav](World.wav)：敌人近战 → 敌人发射 → 敌人光束 → 木质受击 → 金属受击 → 柔软受击 → 木质死亡 → 金属死亡 → 柔软死亡 → 机关开启 → 机关关闭 → 石材碰撞 → 金属碰撞 → 木质碰撞 → 石材碎裂 → 木质碎裂 → 爆炸

每个事件还可以在 `Events/` 单独听；工作台仍在 Tools → 规则游戏 → 音频 → ⑧。原始未裁切素材位于 `Doc/AudioSources/SelectedOriginals/`，完整出处、CC0许可、裁切区间、叠层比例和SHA256在 `SelectedSfxManifest.json`。

## 新旧底材对照

`BeforeAfter.wav` 每组先旧后新，顺序：落地、轻击、玩家受击、木质受击、金属受击、开关开启、石材碎裂、爆炸。每对压到较轻一方的RMS，避免把单纯变响当成质感改善。峰值另设余量，详细起点见 `Timeline.json`。

## 重现

`python3 Tools/Audio/prepare_selected_sfx.py --sources /tmp/rule-audio-sources` 只生成试听和清单；加 `--install` 写入播放WAV，不改Unity银行。需要Python3、numpy、ffmpeg；7z来源需要7zz。已提交的原件足够重现当前选材，无需重新下载；新增选材时，原作者下载包对应关系在脚本PACKS中，默认源缓存不加入仓库。Unity引用和参数通过Editor API接入，后续日常替换直接用工作台，不用重跑准备脚本。

旧 `PlayerFeedbackManifest.json`、`SwishesManifest.json`、`ExplosionBrightManifest.json` 和旧试听仅保留历史对照，不代表当前运行时选材。旧准备脚本会重现历史声音，当前重现入口是 `prepare_selected_sfx.py`。
