# 关卡组件一览

> 一张表看清：**每个组件做什么、怎么进场景、要什么条件**。
> 层级/排序/铺装管线的完整说明见 [关卡搭建工具链与区域瓦片方案](关卡搭建工具链与区域瓦片方案.md)。

## 1. 地图组件（菜单生成：`Tools/规则游戏/地图组件/①~⑳`；⑫⑬⑭⑲ 生成的是**预制体**，⑯ 会连按钮一起摆好）

| # | 组件 | 做什么 | 怎么放 | 必须满足 |
| --- | --- | --- | --- | --- |
| ① | `MovingPlatform` 滑板车 | 在起点和终点之间往复（或单程）运送玩家；站上去会被带走 | 菜单生成，子物体是占位方块 | **Ground 层**；脚本与碰撞体同物体；改完点「终点 = 当前位置」 |
| ② | `Fan` 风扇 | 在一条风道里持续给物体施力，越远越弱 | 菜单生成，风道尺寸由 `_length/_width` 决定 | **Wind 层**；**不要旋转**（方向用 `_direction`） |
| ③ | `OneWayGate` 单向门 | 只允许从一侧通过，另一侧像墙；竖直方向 = 单向地板 / 天窗 | 菜单生成（③ 竖板 · ③b 横板） | **Ground 层**；碰撞体必须**实心**；只认玩家；竖板配水平方向、横板配竖直方向（改了方向点 Inspector 的「重设」） |
| ④ | `BreakableGate` 破门 | 被攻击/重击后碎掉放行 | 菜单生成 | **Ground 层**；实心；只认玩家 |
| ⑤ | `Tube` 水管 | 走进管腔后把玩家翻转 90°，从另一头出去 | 菜单生成 | **Ground 层**（根 + 两壁）；两壁必须**非 Trigger** 且上下分开；根要有 `Rigidbody2D` |
| ⑥ | `SpringPlatform` 弹簧 | 可伸缩的弹簧板，踩上去按胡克定律弹起 | 菜单生成 | **Ground 层**；实心；弹跳速度走 `ISpringSurface` |
| ⑦ | `RailLift` 滑轨 | 三档高度（中位/上升/下沉）的升降平台，高度随「质量规则」变化 | 菜单生成 | **只有车厢在 Ground 层**；脚本在根、碰撞体在子物体；不要缩放根 |
| ⑧ | `PushableBody` 铁箱 | 可推的重物；质量受质量规则影响 | 菜单生成 | **Ground 层（必须）**；Dynamic 刚体；推的是**力**，加速度 = 力 ÷ 质量 |
| ⑨ | `ImpactButton` 大按钮 | 被足够动量撞到时按下（可锁定） | 菜单生成 | **Ground 层**；座实心；读 `IMomentumSource` |
| ⑩ | `RustyGear` 生锈齿轮 | 摩擦倍率低于阈值时松脱旋转 | 菜单生成 | 无层要求；无碰撞体；读规则的摩擦倍率 |
| ⑪ | `OneWayPlatform` 跳穿平台 | **单向**：只能从实心面落地，从背面直接穿过；站上面朝背面按方向键（正常重力下 = S）主动下钻 | 菜单生成 **或** 刷 `OneWay_Logic` 瓦片 | **Ground 层**；瓦片版由 `OneWayField` 逐格生成一格大的碰撞体，铺装时按区域套件铺并染色（改 `_tint`） |
| ⑫ | `GravityBoulder` **巨石断剑** | **先踩地上的解锁按钮**（在此之前放多少次重力反转它都不动）→ 重力反转把巨石举起来 → 碰到天花板按钮（`CityButton`）、被**震裂** → 重力恢复、落地**碎开**撒碎块并**露出剑** → 摩擦反转之后走近拔剑 | **拖预制体** `Prefabs/BoulderSwordMechanism.prefab`（菜单 ⑫ 生成 / 更新它）+ **两个** `Prefabs/BrickCity/CityButton.prefab`（地上解锁 / 天花板震裂）；细节见 [巨石断剑机关](巨石断剑机关.md) | **Ground 层**；巨石开局是 **Static（锁死）**，解锁配法 = **把巨石拖到地上那个 CityButton 的 `FollowMotor`**（与配 Gate 一样），没拖就永远不动；碎块模板必须**禁用**；根节点离地 1.2；**按钮不在预制体里**；按钮是 Trigger，天花板要自己摆 |
| ⑬ | `StoneBody` **纯重力石头** | 一块**方形的石头**：受重力、碰到 CityButton / 摇杆就按下去、**被玩家推得动（但只在摩擦变小时）**。没有碎、没有剑、没有锁 | 菜单 ⑬ 生成 `Prefabs/StoneBoulder.prefab`，拖进场景 | **Ground 层**；Dynamic 30 kg；正常摩擦（μ0.5）静摩擦 147 N > 玩家 60 N → **推不动**；「摩擦 × 削弱」（μ0.15 → 44 N）才推得动，「失效」一推就滑 |
| ⑭ | `SpringBackBody` **回弹块** | 被攻击打得**沿自己的轨道**退开（轻击 ≈0.9 格 / 重击顶到轨道尽头），停一下再**慢慢回正**；**摩擦规则直接改回正速度**：×增强 → 慢到 1/3，×削弱 / ×失效 → 快 3 倍。可当活动挡板 / 竖井踏板 | 菜单 ⑭ 生成 `Prefabs/SpringBackBody.prefab`，拖任意多个。细节见 [受击回正块](受击回正块.md) | **Ground 层**；Kinematic 刚体；**必须有受击箱**（预制体自带，层 10 / **和身体同尺寸**，根缩放时一起变大）；**轨道**默认水平 ±1.5 格（两个**相对锚点**的偏移，竖直填 `(0,−1.5)/(0,1.5)`）—— 块只会在这条线上走 |
| ⑯ | `PhasePlatform` **虚实平台** | 一块能按按钮**翻面**的平台：实化时能站、能挡路，虚化时只剩半透明轮廓、谁都能穿过去。初始实 / 虚可选；按下后**隔 0.5 秒**才切换 | 菜单 ⑯ 生成平台 + **每块平台顶面各一个点按式** `CityButton`（都接在同一个组上：按任意一个翻**全部**）；之前摆好的老平台 / 拉杆式按钮用菜单 **⑯a** 一键整理；细节见 [虚实平台](虚实平台.md) | **Ground 层**；实心碰撞体；按钮 **`Toggle` 不要勾**（点按式，按完平台会复位，任何时刻都能再按；勾了会变拉杆、吃掉别的按钮的按下）；也不要开 `PressByPlayerProximity`；平台都要放进同一个 `PhasePlatformGroup`；实化时玩家正占着空间会等他自己走开；复制平台时按钮跟着走，复制完点组 Inspector 的「从子物体收集平台」 |
| ⑲ | `PunchFist` **拳击手套** | 开关一响就**弹出去**（带过冲的小动画），弹出与停留期间持续给**出拳走廊**（静止位置 → 手套当前位置）里的实体**加速度**，把人 / 敌人 / 铁箱沿出拳方向**推飞**，然后自己收回 | 菜单 ⑲ 生成 `Prefabs/PunchFist.prefab`，拖进场景；旁边放 `CityButton` / `CityLever`，**把拳头拖到开关的 `FollowMotor` 上** | 出拳方向是**根节点的局部 +X**（默认朝右），要朝别的方向就转根节点；**手套没有碰撞体、不挡路**；拉杆（`Toggle`）可反复出拳，按钮按下即锁死只出一次；一次只出一拳（出拳 / 收回途中再按会被忽略）；Play 中右键组件「试打一拳」可脱离开关单独验证 |
| ⑳ | `LaserBlock` **激光发射块** | 沿水平轨道**往返移动**，常驻射出一条激光（**默认朝下**，四向可选）；激光的伤害逻辑与**刺**（`HazardField`）完全同一套：只认受击箱、不套阵营准入、伤害走 `CombatSystem.ApplyDamage`、按间隔重复伤害。**可接开关**控制开 / 关 | 菜单生成，用 Inspector 的「起点 / 终点 = 当前位置」定轨道；激光方向 / 长度 / 粗细 / 伤害都在 Inspector 里调；接开关时**把块拖到 `CityButton` / `CityLever` 的 `FollowMotor` 上** | **Ground 层**（块能站、能挡路；放错层玩家会穿过去，激光照常生效）；起点 / 终点是**世界 X**，Y 永远是摆放高度；激光会被 Ground 层地形截断；开关只控**激光发射**（块照常巡逻），实际状态 = `_startsOn` XOR 开关状态；不参与时间回溯 |

## 2. 积木城组件（拖预制体：`Prefabs/BrickCity/`，14 种）

| 预制体 | 做什么 |
| --- | --- |
| `CityBomb` | 定时/触发爆炸，伤害范围内的目标 |
| `CityThorns` | 静态伤害区（刺） |
| `CityButton` / `CityLever` | 开关：按下/扳动后驱动别的机关。`CityLever` 是**切换型**（按一下开、再按一下关，把手会转），`CityButton` 按一次锁死；交互键由 `CityInteractor` 自己读（E / 手柄 Y） |
| `CityGate` | 受开关控制的闸门 |
| `CityLift` / `CityTrain` | 沿路径运动（`CityPathMotor`，`SolidMask = 1<<8`） |
| `CityFloorLift` | **楼层电梯 + 随车拉杆**（独立预制体，2026-10-19）：车厢在 2~3 个站点间升降，拉杆装在车上跟着走，**按被打中的位置选档**（左 / 中 / 右）。旧的两站电梯完全不受影响，细节见 [楼层电梯与多档拉杆](楼层电梯与多档拉杆.md) |
| `CityMarble` | 可滚动的弹珠，带弹力材质 |
| `CityHammer` | 摆锤式打击机关 |
| `CityBubble` | 泡泡（浮起/承载） |
| `CityRefill` | 回复道具点 |
| `CityReward` / `CityChest` | 奖励与宝箱 |

- 全部继承 `CityMechanism`：状态（路径进度/引信/破裂/冷却）走 `ISnapshotParticipant`，**时间回溯能还原**。
- ⚠️ 要参与回溯必须经 `RuleAffectedBody` 登记进世界注册表；只拖预制体不登记 = 回溯漏掉它。
- 试验场：`Scenes/Test_BrickCityComponents.unity`（F1/F2 切换试验区）。

## 3. 单件组件（拖预制体：`Prefabs/`）

> 整关只用一两次的机关不做一键菜单，**直接从预制体拖进场景**。

| 预制体 | 做什么 | 注意 |
| --- | --- | --- |
| `TrestleTrap` 三棍支架陷阱 | 三根棍子搭的平台：右腿固定，左腿被**质量 ≥ 阈值**（默认 2.5 kg）的实体顶倒，顶梁随即绕右柱顶下摆成**三角斜坡**，并把推动者关在笼内 | **Ground 层**；左腿 / 顶梁要 `Rigidbody2D`(Kinematic) + `BoxCollider2D`，右腿只要 `BoxCollider2D`；**顶梁长（＝两腿跨距）必须大于柱高**，否则转到底会贴着右柱、不成三角形；顶梁静止角由几何**自动算出**，不用手调 |
| `BoulderSwordMechanism` 巨石断剑 | 见 §1 ⑫：举起来 → 碰按钮 → 震裂 → 落地碎开 → 露剑 → 摩擦反转拔剑 | **Ground 层**；根节点离地 1.2；剑 / 碎块模板的引用全在预制体内部。**按钮另拖** `BrickCity/CityButton.prefab`（不在这个预制体里） |
| `StoneBoulder` 纯重力石头 | 见 §1 ⑬：只受重力、碰到开关就按下（没有碎 / 剑 / 锁） | **Ground 层**；Dynamic 40 kg；要驱动巨石就把石头拖到按钮的 `FollowMotor` |

- 触发判据是**质量**（读 `Rigidbody2D.mass`），所以质量规则就是这一关的钥匙：
  「质量 × 削弱」把铁箱压到 2.4 kg 就顶不动了，「质量 × 增强」把玩家压到 3 kg 才顶得动。
  ⚠️ 玩家现在 `mass = 1` 且**没挂** `RuleAffectedBody`，想让玩家自己变重顶倒，得先给玩家挂上它。
- 成型后顶梁默认锁成 Static，笼里的东西顶不开；**不参与时间回溯**（与其余地图组件一致）。

## 5. 关卡流程与地形件

| 组件 | 做什么 | 注意 |
| --- | --- | --- |
| `PlayerSpawnPoint` | **落点 = 出生点 + 存档点**（带 `Id`） | 开局由 `WorldStreamer` 按 `_startEntryId` 落人**并记成复活点**；走到 `_activateRadius`（默认 1.2 m）内自动刷新复活点；死亡后 `PlayerController` 自己回这里。**不需要碰撞体、不需要交互键** |
| `LevelGoalTrigger` | 关卡终点触发 | 自带 Trigger；进入者必须是 `Player` 阵营 |
| `HazardField` | 刺的伤害判定（挂 `Logic` Tilemap） | 刺瓦片 `Collider Type` 必须是 **None**；判定只认 Hurtbox |
| `SecretWallField` | 暗墙管理（挂 `Logic` Tilemap） | 配 `Secret_Logic` 瓦片；揭示时清瓦片 + 删墙皮 |
| `MaskLayer` | 遮罩透明度（编辑器半透明 / 运行时纯黑） | `[ExecuteAlways]`；挂在 `Grid/Mask` |
| `RevealRegion` | 进入区域揭开遮罩 + 暗墙，离开自动补回 | 异形房间用多个子 BoxCollider2D 拼；淡出 0.75 s |
| `SurfaceTile` + `Grid/Ice` | 冰面（0 摩擦） | 冰面单独一层，碰撞体挂 0 摩擦物理材质 |
| `TileRegion` | 区域瓦片：这一片用哪套石材 | 挂 `Grid`；一个分区一套默认，跨王国加矩形覆盖 |
| `WorldStreamer` + `PartitionCatalog` | 分区流式加载 | 场景路径必须与 Build Settings 一致 |
| `GameRoot` / `LevelRuntime` | 运行时根（Systems/Player/Camera/RuleWheel） | 由骨架菜单生成，不要手工粘散件 |

## 6. 交互接口（组件之间的唯一耦合点）

| 接口 | 谁实现 | 谁消费 |
| --- | --- | --- |
| `IMovingSurface` | 滑板车 / 弹簧 / 滑轨 / 铁箱 / 重石 / **回弹块** / **激光块** | `ContactSensor` → `MotionMover`（站上去被带走） |
| `IWindField` | 风扇 / 风场 | `WindSensor`（报力，自己除以质量） |
| `ISpringSurface` | 弹簧 | `VelocitySolver`（弹起速度） |
| `IPushable` | 铁箱 | `PushSensor`（交推力，不交速度） |
| `IMomentumSource` | 玩家 | `ImpactButton`（算动量） |
| `IFactionMember` | `EntityDamageable` | `SwordInStone`（认「玩家阵营」当取剑的人，不认具体类型） |
| `IContactSwitch` | `CitySwitch`（CityButton / 摇杆） | **压住型**：`GravityBoulder` / `StoneBody` / 敌人 / `FitPuzzle`（碰到就 `PressByContact()`，走开 `ReleaseByContact()`）；**撞击型**：玩家攻击盒（`PlayerController.PressSwitches`）与纸飞机（`ThrownKnife.PressSwitch`）调 `ImpactByContact()` —— 打一下就翻转，两边各自去重 |
| `ISwitchTarget` | `CityPathMotor`（门 / 电梯）、`GravityBoulder`（巨石）、`PhasePlatform`（虚实平台）、`PhasePlatformGroup`（一组平台）、`PunchFist`（拳击手套）、`LaserBlock`（激光块） | `CitySwitch.FollowMotor`（拖谁驱动谁：门/电梯走 `SetOn`，其它走 `SetSwitchState`） |
| `PlayerLookup`（静态工具） | — | `CitySwitch`（玩家踩到就按下）、`SwordInStone`（谁算取剑的人） |
