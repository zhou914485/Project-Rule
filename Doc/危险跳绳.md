# 危险跳绳（旋转曲线陷阱）

> 组件：`Gameplay/Scene/SwingRope.cs`
> 菜单：`Tools/规则游戏/地图组件/⑱ 危险跳绳（旋转曲线陷阱）`
> 自检：`规则游戏/验证/危险跳绳（预制体 + 纯函数）`

---

## 1. 一句话

一条**碰到就受伤**的曲线：两端固定在两个点上，绳身绕着这两个点的连线做跳绳运动。
**和尖刺同一条伤害路径**（默认 10 伤害 / 6 击退 / 0.5 秒内同一目标不重复结算）。

## 2. 怎么摆

菜单 **⑱ 危险跳绳** 生成 `Prefabs/SwingRope.prefab`：

```
SwingRope            ← 位置 = 绳子中点；挂 SwingRope，没有碰撞体
├─ AnchorA           ← 白盒圆（纯视觉）
├─ AnchorB           ← 白盒圆（纯视觉）
└─ RopeSegment_00..  ← 运行时才生成：沿曲线摆的一串细长方块
```

- 拖进场景后**移动根物体 = 移动整条绳**；旋转根物体 = 倾斜整根绳（两端点连线跟着转）。
- 两个端点装饰的位置由「两端点距离」自动摆，不用手动对。
- 盘子里的段是**运行时生成**的，编辑器里看不到实体绳 —— 在 Scene 视图里用红色 gizmo 曲线
  预览形状（选中后还会画出判定带）。

## 3. 参数

| 字段 | 含义 |
| --- | --- |
| `_span` | **两个端点之间的距离**（米）。局部单位，随根物体缩放 |
| `_sag` | **曲线到中轴的长度**（垂度，米）：中点离「两端点连线」多远。0 = 一条直线 |
| `_thickness` | 绳子的视觉粗细（米） |
| `_spinSpeed` | **旋转速度**（度 / 秒）。180 = 两秒一圈；负值反向 |
| `_startPhase` | 起始相位（度）。0 = 垂在下方、90 = 拉直、180 = 拱在上方 |
| `_damage` | 基础伤害。0 = 只击退不掉血 |
| `_knockback` | 击退强度 |
| `_repeatInterval` | 同一目标两次受伤的最小间隔（秒）；目标自带无敌帧时以无敌帧为准 |
| `_hitRadius` | 判定半径（世界单位，从绳子中心线往外量） |
| `_combat` | 伤害出口。留空则运行时自动找场景里的 `CombatSystem` |
| `_segmentSprite` | 段用的精灵（默认白盒方块）。留空则运行时用 1×1 白纹理 |
| `_color` / `_farShade` | 绳子颜色 / 转到背面时的亮度比例 |
| `_segmentCount` | 沿曲线切几段（4–48）。越多越圆滑，判定查询也越多 |
| `_sortingOrder` | 段的排序层内顺序 |
| `_anchorA` / `_anchorB` | 两端装饰（纯视觉） |

## 4. 形状与旋转

曲线是**抛物线**（两端 0、中点 1），局部坐标：

```
x = -span/2 + span·t
y = -sag · 4t(1-t) · cos(相位)
```

相位按 `_spinSpeed` 推进，所以侧视看到的是：
**垂下 → 拉成直线 → 拱在上方 → 拉成直线 → 垂下**。

这正是真实跳绳从侧面看过去的投影 —— 绳子在屏幕深处绕过观察者时被压扁成直线。

**正转 / 反转怎么看出来**：颜色。绳子转到「背面」的那一半更暗（`_farShade`），
近处保持原色。所以旋转方向是有视觉反馈的，不是单纯上下摆动。

## 5. 判定

- 只查**受击箱**（`Hurtbox.Mask`，`useTriggers = true`），身体碰撞体压到绳子不算 ——
  和挥砍 / 尖刺 / 纸飞机是同一套几何。
- 伤害走 **`CombatSystem.ApplyDamage`**，传的是**基础伤害**；缩放 / 反转 / 挂账 / 因果
  全由 `DamageProcessor` 处理。**不要**在绳子这边另算最终值。
- 和 `HazardField`（尖刺）一样**不套阵营准入**：绳子对玩家、敌人、中立生物一视同仁。
- 同一物理帧里，一个目标被多段同时压到只结算一次。
- **运动扫掠**：绳子转得快时，每帧除当前曲线外，还会对「上一帧采样点 → 本帧采样点」
  的轨迹做一次胶囊查询，高速甩过的人不会从两帧之间漏掉。

## 6. 实现约束

- **绳子没有碰撞体**：它不是墙，不用「跳过去」，而是「跳过判定」。
  擦着绳子边缘走过去不会掉血 —— 受击箱压到才掉。
- **暂停**：`TimeManager.Instance.IsPaused` 时旋转与判定一起冻结（与尖刺同一条闸门）。
- **规则交互**：绳子不是物理体，重力 / 摩擦 / 质量规则都不影响它；
  **伤害规则照常生效**（它走的是唯一伤害出口）。
- 段是运行时生成的，**不进世界快照**；回溯不会把绳子状态装回去。
- `_hitRadius` 是**世界单位**，不随根物体缩放；`_span` / `_sag` 是局部单位，随缩放。

## 7. 自检

菜单 **`规则游戏/验证/危险跳绳（预制体 + 纯函数）`**，不需要进 Play 模式：

- 曲线几何（端点位置、中点垂度、相位 180° 上拱、相位 90° 拉直、左右对称）；
- 相位推进（180°/秒 × 1 秒 = 180°）；
- 预制体装配（端点位置、精灵接线、参数默认值、**根上没有碰撞体**）。

预制体不存在时会自动生成一次。
